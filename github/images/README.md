# 菜品图片目录

把菜品图片上传到本目录后，网站会从 `github/images/` 读取图片。

默认文件名配置在本目录的 `image-config.js` 中：

- `hero.jpg`：首页背景图
- `bbq-pork-rice.jpg`：蜜汁叉烧饭
- `beef-noodle.jpg`：红烧牛肉面
- `spicy-chicken.jpg`：川香辣子鸡
- `mapo-tofu.jpg`：麻婆豆腐
- `garlic-broccoli.jpg`：蒜蓉西兰花
- `tomato-egg.jpg`：番茄炒蛋
- `spring-rolls.jpg`：脆皮春卷
- `dumplings.jpg`：手工煎饺
- `mango-sago.jpg`：芒果西米露
- `lemon-tea.jpg`：港式冻柠茶

如果你想使用不同文件名，优先修改本目录的 `image-config.js`，不需要改网站主程序。
