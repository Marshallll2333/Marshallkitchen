# 测试清单

## 登录与权限

- 你的 openid 进入厨师端。
- 她的 openid 进入顾客端。
- 未配置 openid 进入私人提示页。
- 顾客无法通过页面跳转访问厨师云函数。

## 顾客端

- 首页只展示库存足够、工具可用、已上架菜品。
- 分类、搜索可用。
- 菜品详情可选择少盐、少油、不放葱、不放蒜、不辣。
- 点菜单可加菜、减菜、删除到 0。
- 整单备注和期望时间能写入订单。
- 提交订单后点菜单清空。

## 厨师端

- 工作台能看到新订单。
- 订单可以接单、开始制作、取消。
- 做菜详情显示调整后的用量。
- 完成出餐后订单状态变为 `READY`。
- 完成出餐后材料和调味料库存减少。
- `stock_logs` 生成扣减记录。

## 真机与部署

- 微信开发者工具预览正常。
- iPhone 微信内可打开。
- Android 微信内可打开。
- 云函数全部部署到同一个云环境。
- 数据库集合权限不允许前端绕过云函数直接读写。
